BASIC LXC COMMANDS

* Start: sudo lxc-start -n Kali
* Attach: sudo lxc-attach -n Kali
* Stop: sudo lxc-stop -n Kali
* List: sudo lxc-ls -f
* Info: sudo lxc-info -n Kali
* Remove: sudo lxc-destroy -n Kali

---------------------------------------------
1- Create a Container
* Create a LXC Container 
sudo lxc-create -n Kali-Linux -t download 
* select the OS, version & architecture
kali – current – amd64
* Start and attach to the container
sudo lxc start -n Kali
sudo lxc attach -n Kali
* Create a user and give him sudo privileges and switch to user mode
adduser <user-name>
usermod -aG sudo <user-name>
su <user-name>

(optional - Only for GNOME users)
4 - Set mutter to allow xwayland to grab inputs

---------------------------------------------

5 - Now from your host - edit the lxc container config file which is available at "/var/lib/lxc/<Your-container-name>/config

sudo nano /var/lib/lxc/Kali/config
# comment all the Network configurations
#lxc.net.0.type = veth
#lxc.net.0.link = lxcbr0
#lxc.net.0.flags = up

add the following lines

lxc.net.0.type = none
#x11-failsafe via X11 or xwayland
lxc.mount.entry = /tmp/.X11-unix tmp/.X11-unix none bind,optional,create=dir 0 0

#Wayland-Compositer mapping
lxc.mount.entry = /run/user/1000/wayland-0 run/user/1000/wayland-0 none bind,optional,create=file 0 0
lxc.mount.entry = /run/user/1000/wayland-0 run/user/0/wayland-0 none bind,optional,create=file 0 0

#Runtimes (Dbus,portals, Pipewire audio and Video )
lxc.mount.entry = /run/user/1000 run/user/1000 none bind,optional,create=dir 0 0
lxc.mount.entry = /run/user/1000 run/user/0 none bind,optional,create=dir 0 0

#DRI - Graphics Hardware accelerated
lxc.mount.entry = /dev/dri dev/dri none bind,optional,create=dir 0 0

#Tools which uses JAVA - burpsuite, Zaproxy - Uses xauth 
lxc.mount.entry = /home/<host-username>/.Xauthority /home/<container-username>/.Xauthority none bind,optional,create=file 0 0
lxc.mount.entry = /home/<hosr-username>/.Xauthority /root/.Xauthority none bind,optional,create=file 0 0

#------------EOF-------------
*Press Ctrl + O to Save
*Press Ctrl + X to Exit

---------------------------------------------
6 - Paste the following lines in Container User's ".bashrc" and container root user ".bashrc"

if [ -n "$WAYLAND_DISPLAY" ] || [ -e "/run/user/$UID/wayland-0" ]; then
    # Host is running Wayland (Daily Driver)
    export XDG_RUNTIME_DIR="/run/user/$UID"
    export WAYLAND_DISPLAY="wayland-0"
    export DISPLAY=":0" # Keep defined so Xwayland apps inside container still function
    export QT_QPA_PLATFORM="wayland;xcb" # Tells Qt apps to use Wayland, fallback to X11
    export GDK_BACKEND="wayland,x11"     # Tells GTK apps to use Wayland, fallback to X11
else
    # Host is running pure X11 (Failsafe)
    export DISPLAY=":0"
    export QT_QPA_PLATFORM="xcb"
    export GDK_BACKEND="x11"
fi

# Java/GUI Font Optimizations - Fonts render clearly
export _JAVA_OPTIONS='-Dsun.java2d.xrender=false -Dawt.useSystemAAFontSettings=lcd -Dswing.aatext=true'
# get Xauth 
export XAUTHORITY="$HOME/.Xauthority"

Note : 
1 - this is a privilege container - if commands like shutdown and reboot is used - it will shutdown or restart the host
2 - As network is shared with HOST and Container - both will have same IP address
3 - Port number conflict can happen if Host and container using the same port
4 - Use ssh to login to the container - as "lxc-attach" has some command line rendering issue

if GUI didn't work correctly add the below lines to host .bashrc file 

xhost +si:localuser:root
xhost +local:
